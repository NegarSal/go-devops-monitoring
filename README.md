# Go DevOps Monitoring

A hands-on DevOps project built with Go, MySQL, Docker, GitHub Actions, Kubernetes, Helm, Prometheus, and Grafana.

## Project Goals

- Build a Go REST API
- Integrate MySQL as the database
- Containerize the application with Docker
- Implement CI/CD using GitHub Actions
- Deploy the application on Kubernetes
- Manage deployment with Helm
- Monitor the application with Prometheus and Grafana
